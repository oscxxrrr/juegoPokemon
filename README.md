## 📌 Sobre el Repositorio

Este repositorio contiene el desarrollo de un **Juego Pokémon** construido con **Symfony**, **PHP** y **MySQL**, apoyado en **Antigravity** durante el desarrollo y gestionado con **GitHub**.

El proyecto estructura la lógica del juego en el backend con **Symfony** y **PHP**, y almacena la información de entrenadores, Pokédex y Pokémon capturados (como puntos de combate) en una base de datos relacional **MySQL**.

## 📂 Contenido y Módulos

El proyecto está organizado en módulos para mantener el código limpio y escalable con **Symfony**:

- **Entrenadores y Equipo:** Gestión de entrenadores (`trainer_id`) y su equipo de Pokémon asociados.

- **Pokédex y Especies:** Catálogo de especies (`pokedex_id`) y datos base del juego.

- **Gestión de Pokémon:** Registro y consulta de Pokémon con sus estadísticas, como puntos de combate (`combat_points`).

- **Lógica de Juego y Persistencia:** Controladores, rutas y consultas en **PHP / Symfony** conectados a **MySQL**.
